# 曼谷 Pinklao 行程摘要

> 住宿基地：**CASA 17 Hotel**（Soi Somdet Phra Pin Klao 17, Arun Amarin, Bangkok Noi），緊鄰 Central Pinklao。
> 交通：步行 / 捷運(BTS/MRT) / Grab 皆可。Pinklao 位於昭披耶河西岸老城區，過河即達大皇宮一帶。
>
> ⚠️ 座標、營業時間、花費均為依公開資訊整理之**概估值**，出發前請再確認。地點 `place_id` 需執行 `fetch_place_ids.py` 並帶入有效 API Key 取得。

## 二、週末景點行程（4 個週末 × 2 天）

### 週末 1：拉達那哥欣老城 + 昭披耶河（離 Pinklao 最近，過河即達）
- **Day 1**：大皇宮 & 玉佛寺 → 臥佛寺(Wat Pho) → Tha Maharaj 河岸商場
  - 美食：Err Urban Rustic Thai（在地泰菜）、Pa Aew 路邊咖哩飯、Savoey 海鮮
- **Day 2**：鄭王廟(Wat Arun) → ICONSIAM → The Jam Factory
  - 美食：SookSiam 室內水上市場美食街、The Never Ending Summer 泰式創意菜

### 週末 2：恰圖恰 + 現代曼谷（週末限定市集）
- **Day 1**：恰圖恰週末市集(Chatuchak，僅週末) → Or Tor Kor 高級市場 → Ari 文青街區
  - 美食：市集椰子冰淇淋、Or Tor Kor 芒果糯米/海鮮、Ari 巷弄咖啡與酒吧
- **Day 2**：Terminal 21 Asok → EmSphere/Em District → Benjakitti 森林公園
  - 美食：Pier 21 平價美食街、EmSphere Food Hall

### 週末 3：唐人街 + 河岸夜景
- **Day 1**：耀華力唐人街(Yaowarat) → 金佛寺(Wat Traimit) → Talat Noi 老社區壁畫
  - 美食：T&K Seafood、Nai Ek 豬肉粥、Hong Sieng Kong 河景咖啡
- **Day 2**：Asiatique 河濱夜市 → Lhong 1919 中式古宅
  - 美食：Baan Khanitha 泰菜、河鮮

### 週末 4：城市綠肺 + 老城散步
- **Day 1**：Bang Krachao 綠肺單車一日遊 → Bang Nam Phueng 水上市場(僅週末)
  - 美食：水上市場炭烤、椰子甜點、現做泰式小吃
- **Day 2**：Phra Athit Road 河岸散步(離 Pinklao 最近) → Khaosan Road 夜生活
  - 美食：Krua Apsorn、Jok Pochana、Khaosan Pad Thai 攤

## 五、檔案輸出

| 檔案 | 說明 |
|---|---|
| `output/bangkok_pinklao.kml` | 完整 KML，4 圖層分類（美食地圖 / 週末景點 / 平日晚上 / 咖啡廳），共 54 個地標 |
| `output/place_ids.json` | 所有地點的 place_id 清單（JSON）；目前為座標骨架，跑過 API 後會填入 place_id |
| `itinerary.md` | 本行程摘要 |

### 如何匯入 Google My Maps
1. 開啟 <https://www.google.com/maps/d/>（Google My Maps）
2. 「建立新地圖」→「匯入」→ 選擇 `output/bangkok_pinklao.kml`
3. 每個分類會成為一個圖層，可分別開關顯示。

### 如何取得官方 place_id
```bash
export GOOGLE_MAPS_API_KEY="你的金鑰"   # 需啟用 Places API
cd bangkok_pinklao_maps
python3 fetch_place_ids.py   # 產生帶 place_id 的 output/place_ids.json
python3 build_kml.py         # 重建 KML，描述中會帶入 place_id 與官方連結
```

> 補充：**Google Maps 並無公開 API 可程式化將地點寫入個人「已儲存清單」**。本工具採官方支援路徑：產生 KML → 匯入 Google My Maps。
